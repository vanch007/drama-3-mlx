# Drama 3 MLX

- Purpose: Standalone Apple Silicon pure MLX port of Fish Audio Drama 3 with full feature parity, official weights conversion, local inference, voice cloning, multi-speaker dialogue, and streaming HTTP serving.
- Package: `src/drama3_mlx`; Python >=3.10; MLX >=0.30.0.
- Interfaces: Python `load_model`/`Drama3Model.generate`, `drama3-mlx` CLI, FastAPI `/v1/audio/speech` (OpenAI streaming format) and `/v1/tts` (Fish Audio native format).
- Upstream reference: `fishaudio/fish-speech` & HuggingFace `fishaudio/drama-3`.
- Architecture:
  - Text Backbone: 35B total / 3B active MoE (40 layers: 30 linear attention GatedDeltaNet + 10 full attention layers, 256 experts top-8 with shared expert, Block-FP8 / BF16 / 8-bit / 4-bit).
  - Codebook Tower (MTP): 10 codebooks decoded causally (4 shared layers + 9 residual codebook layers, RAS repetition-aware sampling).
  - Audio Codec: 44.1kHz 10-codebook Modded DAC (WindowLimitedTransformer + Residual Vector Quantization).
- Official Feature Scope:
  - Zero-shot voice cloning with reference audio + transcript
  - Multi-speaker dialogue (<|speaker:0|> .. <|speaker:15|>)
  - Point tags for emotion and paralinguistics ([sighs], [laughs], [whispers], etc.)
  - Continuation / audio editing (previous_takes context)
  - Automatic long-text chunking (split_drama3_text) preserving speaker tags and natural boundaries
  - Streaming generation chunk-by-chunk
  - Offline weight conversion with FP8 block dequantization and affine quantization
- Runtime constraint: zero dependency on PyTorch or mlx_audio for inference.
